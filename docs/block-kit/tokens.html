Everything here is as-is: the light column is the default skin and the dark column is the .theme-dark / body.dark override the plugin already ships — not a proposal. The palette was migrated to Moodle DS on 2026-07-27 to match the sibling plugin local_dimensions; the retired values are shown struck through for orientation, and the full record is in token-migration.md.

Card gradients — colours migrated, mechanism kept halftone kept

plan card — #0f6cbf → #0a5aa0

The exact gradient local_dimensions uses (its styles.css:2569), so the block's placeholder and the page it links into now match. Was #667eea → #764ba2.

competency card — #ffc107 → #fd7e14 → #e8590c

Still a warm three-stop gradient, still overlaid with the halftone dot grid — radial-gradient(circle, var(--dimension-customtextcolor,#00000082) 0, transparent 1px) at 5px / opacity(.5), untouched. Only the stops moved, onto the orange family local_dimensions keeps as its brand accent. Was #f5af19 → #f12711 → #ef4136.

Keeping one card warm and the other cool is what distinguishes a competency card from a plan card at a glance; migrating both onto primary would have made them identical.

Tag default #fd7e14 Section header gradient

Tag chips read var(--dimension-custombgcolor, #fd7e14) / var(--dimension-customtextcolor, #212529). The default text flipped from white to dark: white on the old #ef4136 was 3.83:1 and failed WCAG 1.4.3 for 12px bold text; dark on #fd7e14 is 6.00:1. Both values are set inline on the card from local_dimensions metadata and hex-validated by dataset_provider::sanitize_color().

Success moved from BS4 #28a745/#1a7431 to BS5 #198754/#0f5132 (dark #75b798, was #4dba6a); the star from #ffb100 to BS5 warning #ffc107. High-contrast mode still replaces card borders and outlines with #000 and flattens the competency gradient to #6c757d; print flattens it to #ced4da.

No pair fails any more. The pending-trail ring used to be a 2px #adb5bd on white — 2.07:1, under the 3:1 non-text floor, and a source comment claimed "≈ 3.1:1", which was never true. It is now 1px #6c757d, 4.69:1: darkening alone would have made every pending step read heavier than the completed ones, so the stroke thinned in the same change — WCAG 1.4.11 constrains the ratio, not the thickness. Dark had the inverse failure (#6c757d on #343a40, 2.45:1) and now uses #adb5bd at 5.55:1. Sweeping for the same problem closed four more dark gaps; see token-migration.md.
