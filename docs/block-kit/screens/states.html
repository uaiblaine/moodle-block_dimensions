Dark restates three of them, all with #6ea8fe: the competency card's ring, plus a rgba(110,168,254,.25) glow (styles.css:355-359); the filter select's outline and border (styles.css:1517-1521); and the mobile toggle's outline, restated inside the same 575.98px query the control lives in (styles.css:1449-1452). Every other ring — the plan card's identical one included — stays #0f6cbf on the dark surface, because no .theme-dark block restates it. Historically this was four different light blues: #005fcc on the card ring, #1a73e8 on everything else, #0a58ca on the access pill alone and #1765cc on the mobile toggle alone, with #66b3ff as a fifth in dark. That spread is why the consolidation happened; it is recorded in token-migration.md. The pill's own ring is gone entirely now — it shares the card's, and answers hover and focus with the same lift instead.

prefers-contrast: high STA-CONTRAST

  • Card gets border: 2px solid #000 and its :focus-within ring turns 3px solid #000 — the only place the focus colour is replaced rather than thickened. Card titles are forced to #000 !important.
  • Competency gradient flattens to a solid #6c757d, so tag contrast is evaluated against one grey instead of three brand stops.
  • Access pill, tags and the favourite star all take 2px solid currentColor and drop their shadows.
  • Filter pills gain 2px solid transparent; the active pill gets a real #0f6cbf border, and the sliding indicator gains outline: 2px solid #0f6cbf; outline-offset: -2px so it reads as a bordered pill rather than a shadowed platter.
  • The select goes 2px solid #000, the clear button 2px solid currentColor, and the ghost card thickens to 3px dashed currentColor.
  • None of these blocks are restated for dark mode — #000 borders are applied on #343a40 cards too.

prefers-reduced-motion: reduce STA-MOTION  ·  print STA-PRINT

  • Reduced motion zeroes every transition (card, access pill, filter pill, select, indicator, paddles, clear button, favourite star, ghost card, the mobile filter host and its toggle) and every transform: card hover, the access pill's translateY(-1px), star hover and :active, ghost hover and :active, and the trail marker's scale(1.2) all become none. Colour and shadow changes survive, so every state stays distinguishable without movement.
  • Print hides the access pill, the tag row, the favourite star, the whole filter bar and the ghost card; the card drops its shadow, forces border: 1px solid #000 and sets break-inside: avoid; the competency gradient flattens to #ced4da !important so a colour image never burns a page.
  • The section header prints as solid #000. Its print override used to set color only, which the base rule's -webkit-text-fill-color: transparent beat, so it painted nothing; it now clears background-image and resets the fill to currentcolor first. The dark override had the same defect and the same fix, and shows #dee2e6.
  • What print does not hide: the trail, the section header, the card title and the competency count — which is the intended paper artefact.
