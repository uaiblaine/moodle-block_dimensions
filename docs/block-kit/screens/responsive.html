Why the grid exists at all: the block ships its cards inside Bootstrap's .row / col-* markup, then overrides it — [data-cards-type] becomes display:grid with the Bootstrap negative margins zeroed, and every >li drops flex/padding/margin-bottom in favour of the 1rem grid gap. Bootstrap columns respond to the viewport; a Moodle block lives in a column whose width the viewport does not describe, so the plugin makes each cell a query container instead. Note the competency grid does not use the clamp — it hardcodes minmax(360px,1fr), so in a block column narrower than 360px its single track overflows the column.
