Loading
Server-rendered in the shell and visible before any fetch resolves; showLoading() only flips display. The string is core loading, not a plugin string.
2 · Error — warning alert + Retry BLK-ERROR BLK-ERROR-RETRY
Unable to load competency cards right now. Please try again.
Only loadData().catch() reaches here. showError() blanks the text, unhides the box, then writes the message on the next frame — a role="alert" that was display:none does not announce reliably otherwise (WCAG 4.1.3).
3 · Empty — no active plans BLK-EMPTY-NOPLANS

No active plans at the moment.

The one state the block class can pre-empt: has_content() returns false and the block never renders. This text appears when plans existed at page build but the dataset comes back with hasactiveplans false — it is checked first and returns early, so it always wins over the competency message.
4 · Empty — no competencies BLK-EMPTY-NOCOMP

No competencies in your plans.

Shown when filters or search reduce both lists to zero and no ghost card is on screen. updateEmptyState deliberately stays silent while a ghost card is visible — "no competencies" would be a lie when more are one click away.
5 · Favourite-toggle error — announced, never drawn BLK-LIVE-FAV
Could not update favourites. Please try again.visually-hidden · assertive
Written into the data-fav-status region, blanked then re-set on the next frame so an identical message still fires, and self-cleared after 5000 ms so it does not linger in the AT cursor. Its sibling data-results-status is polite and debounced by 600 ms so typing in the search box does not flood a screen reader.
6 · No JavaScript BLK-NOSCRIPT

JavaScript is required to load your competency cards in this block.

Deliberately 1rem, not small: it is the only thing a no-JS user ever sees, so it carries legible size and ≥ 4.5:1 contrast (WCAG 1.3.1, 1.4.3).

The ghost card exists because of two-phase loading: with favourites enabled the first request asks for favourites only, so the ghost card is the invitation to fetch the rest. 7b · Ghost card, hover / focus GST-CARD
Hover recolours border, circle and title to the accent and lifts the shell by 2px; focus swaps to a 2px accent outline at 2px offset.
