The trail is a 5-item window centred on the last completed competency — select_trail_competencies() slices 5 around it and get_trail_start_index() clamps the window to the ends of the list; plans with 5 or fewer competencies show them all (card B).
The label flips Access → Continue only when the trail is partially complete (has_partial_trail(): at least one done and at least one not). Card B is 0/3 done, so it stays Access.
The count text is a number plus the template's custom type field ("skills") or, when the template has none, the lang string competency_count_suffix ("competencies").
Card B has no image because neither the template nor the first competency's cached metadata supplied one — only then does the gradient show. The pill is decorative (pointer-events:none, aria-hidden): the real link is the title, stretched over the card by ::after. The star is deliberately excluded from those overlay rules so it keeps its own z-index:3 corner.
Decorative does not mean inert — hover the card or tab into it and the pill lifts -1px, its label turns accent and its shadow grows to 0 4px 14px in the shadow token. The rule is scoped to the <article>, not to the link, which is why it reads unusually: the pill lives in the image wrapper and the link in the card body, so an earlier link-descendant selector could never reach a sibling subtree. stretched-link bubbles both :hover and :focus-within to the article, so the two states share one treatment; the pill takes no ring of its own, because the card already draws the 2px focus-ring outline and a second ring would double up on one focus event. prefers-reduced-motion drops the translate and keeps the shadow.

The custom pair is the same in both modes, and now by rule rather than by omission: --dimension-custombgcolor and --dimension-customtextcolor are admin instance data crossing the plugin boundary, not design tokens, so the mode layer reads them and never declares or overrides them in either mode. A site's chosen brand colour stays its colour when the page goes dark and only the neutrals around it adapt — which also means a light-tuned template colour keeps its contrast burden on the admin who set it. colour_tokens_test fails the build if any mode block ever assigns one.
