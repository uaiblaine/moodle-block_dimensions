Dark abandons the gradient and falls back to flat #dee2e6 — and now genuinely does so. The base rule paints the title with -webkit-text-fill-color:transparent, which outranks any plain color, so the old override set color:#dee2e6 and painted nothing at all; the header only ever looked right in a browser that ignored the clip.
