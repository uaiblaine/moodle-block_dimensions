Elementos novos nesta proposta

FLT-STATUSGrupo de status — radiogroup na mesma bandeja de pílulas dos filtros atuais (.flt-tabs / .flt-tab / .flt-count / .flt-ind). Um balde com contagem 0 não é desenhado. PLN-STATUSSelo de status no cartão — forma do .local-dimensions-grade-badge do plugin irmão, cores dos tons que o bloco já declara: sucesso para concluído, aviso para em revisão. Nada de paleta nova. PLN-SKELETONEsqueleto de carregamento — ocupa a grade enquanto o status pedido chega, com a mensagem de carregamento que o bloco já tem. Sem animação quando o sistema pede movimento reduzido. FLT-SEPSeparador — 1 px entre o grupo de status e os filtros de favoritos, que só existem em "Ativos".
